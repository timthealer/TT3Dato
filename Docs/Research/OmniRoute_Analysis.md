# 2. Что это

OmniRoute — AI-шлюз (AI gateway) нового поколения: унифицированная точка доступа к сотням LLM-провайдеров через один endpoint, с умной маршрутизацией запросов и сжатием контекста.

---

# 3. Ключевые возможности

- **Один endpoint:** единый API-интерфейс для ~290 провайдеров, 500+ моделей, 90+ бесплатных.
- **Бесплатный токен-бюджет:** ~1.53B бесплатных токенов в месяц через ротацию провайдеров.
- **Умная маршрутизация:** 19 стратегий маршрутизации (стоимость, скорость, доступность, каскад и др.).
- **Компрессия контекста:** RTK + Caveman — экономия 15–95% токенов (в среднем ~89%).
- **MCP:** 104 инструмента через MCP-сервер.
- **A2A:** поддержка протокола Agent-to-Agent.
- **CLI:** 80+ команд управления.
- **Local-first:** работает полностью локально, без облака.
- **Безопасность:** шифрование AES-256-GCM.
- **Интернационализация:** 43 языка.
- **Сообщество:** 500+ контрибьюторов.

---

# 4. Архитектура (в контексте TT3Dato)

- OmniRoute закрывает потребность TT3Dato в дешёвом доступе к LLM для массовых операций (аудит, исследование, генерация).
- Сжатие контекста (RTK + Caveman) напрямую снижает стоимость массовых исследовательских задач.
- Маршрутизация (бесплатные/дешёвые провайдеры) подходит для фоновых агентов TT3Dato.
- Применимо как **внешняя интеграция**, а не часть ядра системы.
