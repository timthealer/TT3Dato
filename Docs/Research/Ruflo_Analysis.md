# 2. Что это

Ruflo — агентный харнесс (agent meta-harness) с открытым исходным кодом. Позволяет создавать, подключать и запускать множество AI-агентов, которые совместно решают задачи и взаимодействуют через MCP (Model Context Protocol).

Для TT3Dato это репозиторий, из которого заимствованы два агента: Researcher (`deep-researcher.md`) и Auditor (`dossier-investigator.md`).

---

# 3. Ключевые возможности

- **MCP-сервер** — 323 инструмента для AI-агентов.
- **CLI** — 45 команд управления агентами и рабочими процессами.
- **Плагины** — 38 плагинов, расширяющих функциональность.
- **Агенты** — определяются в `plugins/*/agents/*.md` и `v3/agents/*.yaml`.
- **Рабочие процессы** — `workflows/*.yaml`, включая workflow исследования компаний.
- **База агентов** — бинарный `agentdb.rvf` (не читается напрямую).
- **Интеграции** — Claude Code, Gemini CLI, Aider и др.
- **Универсальный инструментарий** — исследование, аудит, генерация кода, расследования.

---

# 4. Архитектура (в контексте TT3Dato)

Используется Ruflo как **методологический источник**, а не как полная установка:

- Установка всего Ruflo (MCP-сервер, CLI, agentdb.rvf) отклонена — это тяжёлая внешняя зависимость.
- Заимствованы только методологии: структура агента (system.md), подход к многоисточниковому исследованию (deep-research skill), подход к построению досье (dossier-collect skill).
- MCP-инструменты заменены на нативные: `webfetch`, `Git`, `Read/Grep/Glob`.
