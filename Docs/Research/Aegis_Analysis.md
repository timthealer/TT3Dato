# 2. Что это

Aegis — персональный AI-агент с фокусом на безопасность, автономность и верифицируемую память. Проект в стадии MVP (Sprint 10): ранняя разработка, один автор, недавно создан.

---

# 3. Ключевые возможности

- **Trust-домены:** разделение контекста на домены доверия — изолирует данные по уровням доступа.
- **Карантин ввода:** проверка входных данных перед обработкой.
- **Верифицируемая память:** переход знаний из статуса «unverified» в «verified»; только верифицированная память используется при решениях.
- **«Lethal trifecta»:** сочетание доменов доверия, верифицируемой памяти и безопасности ввода.
- **Бюджет как контракт:** бюджет расходования — жёсткий контракт для агента (защита от перерасхода).
- **Каналы:** Telegram-бот + WebChat.
- **Хранилище:** better-sqlite3, Node LTS.
- **Размер ядра:** ~7.5K LOC (по заявлению автора).
- **Особенность:** агент НЕ полагается на долгосрочную память в ранних спринтах; автономия строится на безопасности.

---

# 4. Архитектура (в контексте TT3Dato)

- Trust-домены напрямую применимы к TT3Dato: изоляция данных разных клиентов при аудите компаний.
- Верифицируемая память («unverified» -> «verified») совпадает с принципом TT3Dato «Истина хранится только внутри TT3Dato» (Конституция, раздел 9).
- Бюджет как контракт полезен для контроля расходов на LLM и исследования.
- Карантин ввода применим как защита от prompt injection при обработке внешних данных.
