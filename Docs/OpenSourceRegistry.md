# OpenSourceRegistry

**Версия:** 1.0
**Дата:** 2026-08-02
**Методология:** адаптирована из sindresorhus/awesome (курируемый каталог, критерии качества, PR-модель контрибуций). CC0/MIT — источник идеи формата.

Энциклопедия решений для TT3Dato. Правило Конституции (раздел 4): перед созданием своего — минимум 5 альтернатив; решение регистрируется здесь до подключения.

---

# Правила

- Каждая запись обязана иметь все поля из раздела «Формат записи».
- Ничего не подключается в TT3Dato без статуса `USED` (после проверки совместимости и согласования владельцем).
- Кандидаты добавляются после сканирования (в т.ч. через awesome-разделы), но остаются `CANDIDATE`/`MONITORING` до проверки.
- Устаревшие/отклонённые помечаются `REJECTED` с причиной (не удаляются).

# Статусы

| Статус | Значение |
|---|---|
| USED | Подключено и используется |
| CANDIDATE | Прошло первичную оценку, ждёт проверки/решения |
| MONITORING | Наблюдаем, не внедряем |
| REJECTED | Отклонено с причиной |

# Формат записи

- **Repository** — имя и ссылка
- **Что умеет** — ключевые возможности
- **Какие роли/потребности закрывает** — какую роль или потребность TT3Dato закрывает
- **Язык**
- **Лицензия**
- **Последний коммит / активность**
- **Зрелость**
- **Совместимость** — язык, архитектура, интеграция
- **Статус**
