# TT3DatoE

Веб-интерфейс AI-ассистента (React + Vite + TypeScript), русский язык.
Работает через ваш **omni-роутер** (OpenAI-совместимый API), не требует своего сервера.

> Этап «веб»: все фичи сначала отлаживаются здесь, потом упаковываются в
> Android-приложение (`AndroidApp/`).

## Возможности

- **Чат с AI-агентом** — потоковые ответы (SSE), история в localStorage.
- **Задачи** — список с этапами: новая / в работе / готова / ошибка.
- **Модели** — пресеты (DeepSeek, Qwen, GLM, Kimi, MiniMax, GPT, Claude) или своя.
- **Файлы и проекты** — Markdown-документы, хранятся локально.
- **Настройки** — адрес omni-роутера, API-ключ, модель, температура, системный промпт.

## Лимит токенов

По умолчанию **отключён**: `max_tokens` не отправляется в API, роутер отвечает
без обрезки. Ограничение можно включить в настройках.

## Настройка

1. Откройте вкладку «Настройки».
2. Введите адрес роутера (например, `https://ваш-роутер.example.com/v1`) и API-ключ.
3. Выберите модель во вкладке «Модели» и начните чат.

Ключ хранится только в браузере (localStorage).

## Разработка

```bash
npm install
npm run dev       # dev-сервер с hot-reload
npm run build     # сборка (tsc + vite)
npm run preview   # превью продакшн-сборки
```
