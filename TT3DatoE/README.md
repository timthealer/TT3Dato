# TT3DatoE

Веб-интерфейс полностью бесплатного AI-ассистента (React + Vite + TypeScript),
русский язык. Приложение само маршрутизирует запросы между бесплатными
провайдерами (Google Gemini, OpenRouter :free, Groq, Cloudflare Workers AI),
выбирая лучшую модель под тип задачи — для непрерывного вайбкодинга без оплаты.

> Этап «веб»: все фичи сначала отлаживаются здесь, потом упаковываются в
> Android-приложение (`AndroidApp/`).

## Возможности

- **Чат с AI-агентом** — потоковые ответы (SSE), история в localStorage.
- **Авто-выбор модели под задачу** — код / рассуждения / чат / быстро, с
  автоматическим переключением на другого провайдера при ошибке или лимите.
- **Бесплатные провайдеры** — Gemini, OpenRouter, Groq, Cloudflare. Ключи
  бесплатные, пользователь вводит их в настройках.
- **Свой роутер (опция)** — поддержка OmniRoute и OpenAI-совместимых шлюзов.
- **Задачи** — список с этапами: новая / в работе / готова / ошибка.
- **Модели** — список бесплатных моделей включённых провайдеров.
- **Файлы и проекты** — Markdown-документы, хранятся локально.

## Лимит токенов

По умолчанию **отключён**: `max_tokens` не отправляется в API. Ограничение
можно включить в настройках.

## Настройка

1. Откройте вкладку «Настройки».
2. Получите бесплатный ключ любого провайдера (ссылки «Получить ключ» рядом с
   каждой карточкой) и вставьте его.
3. Включите провайдер, нажмите «Проверить» — и начните чат.

Ключи хранятся только в браузере (localStorage).

## Разработка

```bash
npm install
npm run dev       # dev-сервер с hot-reload
npm run build     # сборка (tsc + vite)
npm run lint      # oxlint
npm run preview   # превью продакшн-сборки
```
