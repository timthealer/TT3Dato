# AGENTS.md — инструкции для AI-агента

Проект: **TT3DatoE** — полностью бесплатный русскоязычный AI-ассистент
(React + Vite + TypeScript). Работает в браузере, ключи хранятся в localStorage.

## Как работать с этим проектом

Перед началом задачи прочитай правила в `.ai-ready/rules/`:

- `.ai-ready/rules/01-style.md` — стиль и конвенции кода.
- `.ai-ready/rules/02-commands.md` — команды сборки, lint, dev.
- `.ai-ready/rules/03-workflow.md` — порядок работы над задачей.
- `.ai-ready/rules/04-commit.md` — как коммитить и пушить.
- `.ai-ready/rules/05-providers.md` — архитектура бесплатных провайдеров.

Для типовых задач используй скиллы из `.ai-ready/skills/` (например,
`add-provider` — добавить нового бесплатного провайдера, `deploy-preview` —
запустить dev-сервер и показать превью).

## Главные принципы

- Приложение бесплатно и без своего сервера: только бесплатные API-ключи
  (Gemini, OpenRouter :free, Groq, Cloudflare), плюс опциональный свой роутер.
- Не хардкодь API-ключи и секреты в код. Все ключи пользователь вводит сам.
- Русский язык интерфейса.
- После изменений всегда запускай `npm run build` и `npm run lint`.
