# Архитектура бесплатных провайдеров

## Суть

TT3DatoE — бесплатный AI-ассистент. Он не привязан к одному серверу, а сам
маршрутизирует запросы между бесплатными провайдерами, выбирая лучшую модель
под тип задачи (вайбкодинг без оплаты).

## Ключевые файлы

- `src/types.ts` — типы. `PROVIDER_META` описывает каждого бесплатного
  провайдера (адрес, модели, их качество и типы задач), `ProviderConfig` —
  настройки пользователя (ключ, включён ли). `TASK_MODES` — режимы выбора.
- `src/api.ts` — логика роутера:
  - `endpointFor(id, cfg)` — строит endpoint и заголовки для провайдера.
  - `detectTask(messages)` — определяет тип задачи по тексту (код/рассуждения/
    чат/быстро), когда выбран режим «Авто».
  - `buildCandidates(settings, messages)` — сортирует модели по качеству под
    задачу среди включённых провайдеров.
  - `chatCompletion(...)` — идёт по кандидатам по очереди (fallback при ошибке).
  - `testProvider(id, cfg)` — проверка ключа/подключения.
- `src/screens/SettingsScreen.tsx` — UI настройки ключей, активного провайдера,
  режима задач.

## Как добавить нового бесплатного провайдера

Используй скилл `add-provider`. Кратко:

1. В `src/types.ts` добавь id в `ProviderId`, записи в `PROVIDER_META`
   (baseUrl, signup, модели с `quality` и `tasks`) и дефолт в `DEFAULT_PROVIDERS`.
2. В `src/api.ts` добавь ветку в `endpointFor`.
3. Настройки и ModelsScreen построятся автоматически по `PROVIDER_META`.

## Как добавить бесплатную модель существующему провайдеру

Добавь запись в `models` нужного провайдера в `PROVIDER_META`. Модель появится
в кандидатах автоматически.

## Важно

- Свой роутер (OmniRoute и др., id `custom`) — опция, работает как
  дополнительный кандидат. Не делай его основным.
- Ключи пользователя — только в localStorage, никогда не в коде.
