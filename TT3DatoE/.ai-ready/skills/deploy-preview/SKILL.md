# Skill: deploy-preview

Запустить dev-сервер TT3DatoE и показать пользователю превью-ссылку.

## Когда использовать

Когда пользователь хочет посмотреть/проверить веб-интерфейс, или после
существенных изменений нужно показать результат в браузере.

## Шаги

### 1. Проверь dev-сервер

Если на :5173 уже работает Vite — пропусти шаг 2. Проверка:

```bash
curl -s -m 8 http://localhost:5173 -o /dev/null -w "HTTP %{http_code}\n"
```

### 2. Запусти dev-сервер в фоне

Используй фоновый терминал (не блокируй сессию):

```bash
cd /workspace/TT3DatoE && npm run dev -- --host
```

Дождись в логе строки `ready in ... ms`, затем проверь HTTP 200 на :5173.

### 3. Запроси превью

Запроси превью для порта 5173 и покажи пользователю ссылку вида:

```
https://5173-<sandbox>.monkeycode-ai.live
```

### 4. Проверь прокси к OmniRoute (опционально)

Прокси `/v1` → `http://localhost:20128` уже настроен в `vite.config.ts`.
Проверить:

```bash
curl -s -m 8 http://localhost:5173/v1/models -o /dev/null -w "HTTP %{http_code}\n"
```

HTTP 200 означает, что прокси до OmniRoute работает (если роутер запущен).

## Важно

- Dev-сервер — долгоживущий процесс, держи его в фоновом терминале.
- Не убивай чужие процессы `pkill`/`killall` — только через управление фоновыми
  терминалами.
