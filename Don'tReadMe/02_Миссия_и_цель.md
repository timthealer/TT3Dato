# Миссия и цель

## Глобальная миссия

Построить **автономную систему жизнеобеспечения** — вода, еда, энергия, нутриенты — независимо от внешних систем.

Личная траектория:

1. Заработать **$1,5 млн**.
2. Купить **10 квартир** (обеспечить жену и дочку).
3. Построить **автономную лодку/яхту** (опреснитель, ферма, солнечные панели).
4. **Уйти в кругосветку.**

Долгосрочное видение: **мобильная цивилизация**, морская биотехнология.

## Миссия TT3Dato

TT3Dato — это не «ещё один чат-бот» и не «один огромный AI-агент». Это **эволюционирующая инженерная среда**, которая:

- умеет получать задачу → исследовать → проводить аудит → предлагать решение → дождаться разрешения → изменить репозиторий;
- собирает себя из **лучших существующих open-source решений** (Open Source First), а не из самодельного кода;
- **сама развивается**: ищет новые инструменты, сравнивает, подключает лучшее, постоянно улучшает собственные процессы (plan → test → implement → review → verify → remember → improve);
- растёт из **одного сильного агента** (HuckleberryFinn) с ролями-режимами, а не из армии агентов;
- контролируется владельцем: никаких изменений без его разрешения.

Бизнес-назначение TT3Dato:

- **аудит компаний** (находить рутинные процессы, точки автоматизации, слабые места);
- **подготовка предложений** по автоматизации и их внедрение;
- **накопление знаний** и построение собственной «энциклопедии» open source.

## Цель ближайшего периода (MVP)

> **Один законченный вертикальный срез:** ты ставишь Геку задачу → Гек понимает → Researcher исследует → Auditor проверяет → Гек формирует решение и объясняет, что и зачем → ты разрешаешь → система вносит изменение → результат фиксируется в Git.

Если этот цикл работает надёжно — **TT3Dato родился**. Всё остальное — масштабирование.

## Критерий успеха

Не количество папок, агентов, звёзд или строк кода. Один сценарий выше, выполняемый надёжно и повторяемо.
