# Don'tReadMe

Личное досье владельца. Здесь лежат файлы, загруженные через Telegram (HuckleberryFinnBot), — выгрузка переписки владельца с GPT о том, кто он, его миссия, идеи, проекты и цели.

Папка предназначена для HuckleberryFinn: **прочитать, сделать заметки, предложить структуру**, а затем на основе понимания владельца — предложить коррективы в главный промт/скилл.

## Назначение

- «кто я»: биография, позиция, миссия;
- «мои идеи»: концепции, задумки, проекты;
- «чего я хочу»: цели, приоритеты, ожидания от TT3Dato.

## Правила

- Папка приватная (репозиторий приватный) — содержимое не выносится в публичные артефакты.
- Файлы загружаются ботом автоматически в корень этой папки с исходными именами.
- HuckleberryFinn не читает папку целиком без необходимости: обрабатывает только новые файлы, помечает прочитанные в `_PROCESSED.md`.
