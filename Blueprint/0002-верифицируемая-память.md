# ADR-0002: Верифицируемая память

> Источник методологии: https://github.com/DukeDeSouth/aegis (MIT). Адаптировано для TT3Dato.

**Статус:** Предложено (Candidate)

---

## Контекст

Конституция TT3Dato (раздел 9): «Истина хранится только внутри TT3Dato». Память из произвольных источников (чат, внешние данные, подсказки) не должна напрямую влиять на решения агентов.

## Решение

Ввести двухстатусную модель памяти (формат `ecc.memory.v1`, см. `Memory/README.md`):

- **unverified** — запись из ненадёжного источника; не используется в решениях;
- **verified** — запись, подтверждённая авторитетным источником (документ, реестр, проверенный источник); используется при решениях.

Переход `unverified -> verified` происходит через явную проверку человеком или авторитетным агентом (Auditor). Записи хранятся в Markdown (`Memory/`), проектном и пользовательском скоупе.

## Последствия

- Плюсы: защита от prompt injection и «ложной памяти»; прозрачность источника каждого знания; согласуется с Aegis (verifiable memory) и ECC (memory is unreviewed context).
- Минусы: требуется процесс проверки; часть знаний временно недоступна для решений.

## Связанные решения

- ADR-0001 (домены доверия) — память из Untrusted не верифицируется автоматически.
- Memory Vault (стандарт `Memory/README.md`).
