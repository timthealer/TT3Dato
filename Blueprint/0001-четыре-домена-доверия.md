# ADR-0001: Четыре домена доверия

> Источник методологии: https://github.com/DukeDeSouth/aegis (MIT). Адаптировано для TT3Dato.

**Статус:** Предложено (Candidate)

---

## Контекст

TT3Dato проводит аудит компаний и обрабатывает внешние данные. Контекст и данные агентов необходимо изолировать по уровням доступа, чтобы данные одного клиента не смешивались с данными другого и не попадали в чужие решения.

## Решение

Ввести четыре домена доверия для всех данных и контекста агентов TT3Dato:

1. **Untrusted** — необработанные внешние данные (ввод пользователя, парсинг чужих источников). Обрабатываются только в карантине.
2. **Internal** — внутренние данные TT3Dato: документы, конфигурации, реестры.
3. **Restricted** — данные отдельных клиентов/проектов при аудите (изолированы между собой).
4. **Public** — открытые источники и опубликованные отчёты.

Данные переходят между доменами только через явный разрешённый путь (проверку/верификацию).

## Последствия

- Плюсы: изоляция клиентских данных; снижение риска перекрёстных утечек; понятные границы для аудита.
- Минусы: дополнительная дисциплина при работе агентов; необходимость маркировать данные.

## Связанные решения

- ADR-0002 (верифицируемая память) — память из Untrusted не попадает в решения без верификации.
