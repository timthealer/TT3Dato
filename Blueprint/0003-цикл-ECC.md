# ADR-0003: Цикл ECC как обязательный процесс

> Источник методологии: https://github.com/affaan-m/ECC (MIT). Адаптировано для TT3Dato.

**Статус:** Принято

---

## Контекст

TT3Dato нуждается в едином рабочем процессе для всех агентов. Без него решения принимаются хаотично, без проверки и памяти об опыте.

## Решение

Принять цикл ECC как обязательный процесс для всех агентов TT3Dato (зафиксировано в Конституции, раздел 15):

`plan -> test -> implement -> review -> verify -> remember -> improve`

- plan — спланировать действие;
- test — проверить гипотезу тестами;
- implement — реализовать;
- review — критический анализ (Critic Protocol);
- verify — подтвердить корректность;
- remember — сохранить решение в память (Memory Vault);
- improve — улучшить процесс на основе опыта.

Библиотеки ECC не устанавливаются; перенимается только методология (см. `Docs/ATTRIBUTIONS.md`).

## Последствия

- Плюсы: единый процесс, evidence trail для каждого результата, непрерывное улучшение.
- Минусы: формализация требует дисциплины у агентов.

## Связанные решения

- ADR-0002 (верифицируемая память) — шаг `remember`.
