# Глубокое исследование (Deep Research)

> **Склонный к дрейфу skill.** Имена инструментов MCP Firecrawl/Exa, квоты и формы результатов
> меняются. Проверьте настроенные MCP-инструменты и текущую документацию API, прежде чем
> обещать покрытие или цитировать живые подсчёты источников.

Создавайте тщательные, цитируемые исследовательские отчёты из множества веб-источников, используя MCP-инструменты firecrawl и exa.

## Когда активировать

- Пользователь просит исследовать любую тему в глубину
- Конкурентный анализ, оценка технологий или оценка рынка
- Due diligence по компаниям, инвесторам или технологиям
- Любой вопрос, требующий синтеза из множества источников
- Пользователь говорит "research", "deep dive", "investigate" или "what's the current state of"

## Требования к MCP

Как минимум одно из:
- **firecrawl** — `firecrawl_search`, `firecrawl_scrape`, `firecrawl_crawl`
- **exa** — `web_search_exa`, `web_search_advanced_exa`, `crawling_exa`

Оба вместе дают наилучшее покрытие. Настройте их в конфигурации MCP агентов TT3Dato.

## Рабочий процесс

### Шаг 1: Поймите цель

Задайте 1-2 быстрых уточняющих вопроса:
- "Какова ваша цель — обучение, принятие решения или написание чего-то?"
- "Есть ли конкретный угол или глубина, которые вам нужны?"

Если пользователь говорит "просто исследуй это" — двигайтесь вперёд с разумными значениями по умолчанию.

### Шаг 2: Спланируйте исследование

Разбейте тему на 3-5 исследовательских подвопросов. Пример:
- Тема: "Влияние ИИ на здравоохранение"
  - Каковы основные применения ИИ в здравоохранении сегодня?
  - Какие клинические результаты были измерены?
  - Каковы регуляторные вызовы?
  - Какие компании лидируют в этой области?
  - Каков размер рынка и траектория роста?

### Шаг 3: Выполните многоисточниковый поиск

Для КАЖДОГО подвопроса ищите с помощью доступных MCP-инструментов:

**С firecrawl:**
```
firecrawl_search(query: "<keywords подвопроса>", limit: 8)
```

**С exa:**
```
web_search_exa(query: "<keywords подвопроса>", numResults: 8)
web_search_advanced_exa(query: "<keywords>", numResults: 5, startPublishedDate: "2025-01-01")
```

**Стратегия поиска:**
- Используйте 2-3 разных варианта ключевых слов на подвопрос
- Смешивайте общие и новостные запросы
- Стремитесь к 15-30 уникальным источникам в сумме
- Приоритет: академические, официальные, авторитетные новости > блоги > форумы

### Шаг 4: Глубокое чтение ключевых источников

Для наиболее перспективных URL получите полное содержимое:

**С firecrawl:**
```
firecrawl_scrape(url: "<url>")
```

**С exa:**
```
crawling_exa(url: "<url>", tokensNum: 5000)
```

Читайте 3-5 ключевых источников полностью для глубины. Не полагайтесь только на сниппеты поиска.

### Шаг 5: Синтезируйте и напишите отчёт

Структурируйте отчёт:

```markdown
# [Тема]: Исследовательский отчёт
*Сгенерировано: [дата] | Источники: [N] | Уверенность: [Высокая/Средняя/Низкая]*

## Executive Summary
[Обзор ключевых находок в 3-5 предложениях]

## 1. [Первая главная тема]
[Находки с встроенными цитатами]
- Ключевая точка ([Название источника](url))
- Подтверждающие данные ([Название источника](url))

## 2. [Вторая главная тема]
...

## 3. [Третья главная тема]
...

## Key Takeaways
- [Действенный инсайт 1]
- [Действенный инсайт 2]
- [Действенный инсайт 3]

## Sources
1. [Название](url) — [однострочная сводка]
2. ...

## Methodology
Искали [N] запросов по вебу и новостям. Проанализировано [M] источников.
Исследованные подвопросы: [список]
```

### Шаг 6: Доставка

- **Короткие темы**: опубликуйте полный отчёт в чате
- **Длинные отчёты**: опубликуйте executive summary + key takeaways, сохраните полный отчёт в файл (например, в `Docs/` TT3Dato)

## Параллельное исследование с субагентами

Для широких тем используйте инструмент Task агентов TT3Dato для распараллеливания:

```
Запустите 3 исследовательских агента параллельно:
1. Агент 1: исследует подвопросы 1-2
2. Агент 2: исследует подвопросы 3-4
3. Агент 3: исследует подвопрос 5 + сквозные темы
```

Каждый агент ищет, читает источники и возвращает находки. Основная сессия синтезирует финальный отчёт.

## Правила качества

1. **Каждое утверждение нуждается в источнике.** Никаких утверждений без источника.
2. **Перекрёстная проверка.** Если это говорит только один источник, пометьте как непроверенное.
3. **Актуальность имеет значение.** Предпочитайте источники за последние 12 месяцев.
4. **Признавайте пробелы.** Если вы не нашли хорошей информации по подвопросу, скажите об этом.
5. **Без галлюцинаций.** Если вы не знаете, скажите "недостаточно данных найдено".
6. **Отделяйте факты от выводов.** Явно помечайте оценки, прогнозы и мнения.

## Примеры

```
"Research the current state of nuclear fusion energy"
"Deep dive into Rust vs Go for backend services in 2026"
"Research the best strategies for bootstrapping a SaaS business"
"What's happening with the US housing market right now?"
"Investigate the competitive landscape for AI code editors"
```
