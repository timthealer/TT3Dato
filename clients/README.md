# Clients

Папка данных по клиентам для аудита и автоматизации.

## Структура

```
clients/
  registry.json          # реестр клиентов: chat_id, slug, название, статус
  <client-slug>/         # папка одного клиента (slug = client-<chat_id>)
    profile.md           # основная информация о клиенте
    interview.md         # протокол опроса (вопрос-ответ)
    voice/               # голосовые ответы клиента (.ogg)
    dossier.md           # сформированное досье (создаётся после опроса)
    audit.md             # аудит + предложения по автоматизации (создаёт HuckleberryFinn)
```

## Статусы клиента

- `interview` — идёт сбор информации (бот задаёт вопросы).
- `dossier` — досье собрано, ждёт аудита.
- `audited` — аудит готов, документ передан клиенту.

## Реестр

`registry.json` ведёт бот автоматически (при первом сообщении клиента) и вручную (для известных клиентов). Поле `chat_id` — Telegram id клиента.

## Обработка

- HuckleberryFinn читает `clients/<slug>/interview.md` после завершения опроса.
- По протоколу строит `dossier.md`, затем `audit.md` (аудит компании + что автоматизируем + предложение).
- Готовый `audit.md` отправляется клиенту (через клиентского бота или вручную).

Источник паттерна: Aegis (MIT) + Telegram funnel. Адаптировано для TT3Dato.
