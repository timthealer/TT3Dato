# AI-ассистент (Android)

Автономное Android-приложение-ассистент на русском языке, работающее через ваш
**omni-роутер** (OpenAI-совместимый API). Не требует собственного сервера —
приложение пишет прямо к роутеру.

## Возможности

- **Чат с AI-агентом** — диалог с сохранением истории на устройстве, потоковые ответы (SSE).
- **Задачи** — список задач с этапами: новая / в работе / готова / ошибка.
- **Модели** — выбор модели из пресетов (DeepSeek, Qwen, GLM, Kimi, MiniMax, GPT, Claude) или своя.
- **Файлы и проекты** — документы в формате Markdown, хранятся локально.
- **Настройки** — адрес omni-роутера, API-ключ, модель, температура, системный промпт.

## Лимит токенов

По умолчанию лимит **отключён**: `max_tokens` не отправляется в API, и роутер
отвечает без обрезки. Ограничение можно включить в настройках приложения.

## Подключение к omni-роутеру

1. Установите APK из `downloads/AI-ассистент-v1.0.1.apk`.
2. Откройте вкладку «Настройки».
3. Обязательно введите адрес роутера (например, `https://ваш-роутер.example.com/v1`) и API-ключ.
4. Выберите модель в разделе «Модели» и начните чат.

Ключ хранится только на устройстве.

## Сборка из исходников

```bash
# установка зависимостей
npm install

# генерация нативного android-проекта
npx expo prebuild --platform android

# сборка APK (требуется JDK 17 и Android SDK)
cd android
export ANDROID_HOME=/opt/android-sdk
./gradlew assembleRelease
```

Готовый APK появится в `android/app/build/outputs/apk/release/app-release.apk`.

## Лицензия

Приложение написано с нуля по мотивам возможностей открытой платформы
[MonkeyCode](https://github.com/chaitin/MonkeyCode) (AGPL-3.0). Код MonkeyCode не
используется. Это самостоятельный автономный клиент к omni-роутеру.
